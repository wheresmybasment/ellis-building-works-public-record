# Evidence files

No court PDFs are included in this repository at present.

Only actual preserved public records may be added here. Before publication, review
each record for current access restrictions and redact unnecessary personal data,
including full dates of birth, private addresses and phone numbers, account details,
signatures, children's information, and confidential or sealed material.

Do not create or link placeholder PDFs. Case pages currently contain text-only
placeholders that accurately state that the corresponding redacted document has not
yet been published.
